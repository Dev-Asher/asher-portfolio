04 — Process

How a project runs.

  1. 01

    Plan

    Agree on the pages, content, and structure first — a simple sitemap before any code.

  2. 02

    Build

    Semantic HTML for structure, CSS for layout and type, JavaScript only where it adds real value.

  3. 03

    Test

    Check narrow screens, keyboard navigation, contrast, links, and the console before calling it done.

  4. 04

    Ship

    Deploy to GitHub Pages, share the link, and keep the repo clean so anyone can read the code.
